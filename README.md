# Zihad — Portfolio
Static site. Open `index.html`, or deploy the folder to Vercel / Netlify / GitHub Pages.

## Edit
- Links, email, APK, project URLs: top of `script.js` (`portfolioConfig`).
- Replace `YOUR-DOMAIN.com` in `index.html` (canonical + og:image).
- Images: `assets/images`, `assets/projects`.
- Stats: `.stats` block in `index.html`.
- Accent color: `--ac` in `style.css`.
